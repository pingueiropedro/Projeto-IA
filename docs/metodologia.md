## Como o TDSP e o CRISP-DM se aplicam a este projeto

CRISP-DM - É focado no ciclo de vida analitico do projetode dados, como por exemplo ir do entendimento do problema a um modelo/analise validada

TDSP - Vai além das fases analiticas, também organiza o processo de equipe, estrutura de repositório e artefatos de governança

Neste projeto, o TDSP guia a organização de pastas e documentos (o "como"), enquanto o CRISP-DM guia o raciocínio analítico dentro de cada etapa (o "o quê" fazer em cada fase).
